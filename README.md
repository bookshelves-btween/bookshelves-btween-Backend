## 📱 소개

### **“ 책장을 공유하는 사이”**

“책은 읽었는데, 이 감상을 누구랑 나누지?”
“독서모임은 부담스럽고, 혼자 기록하기엔 아쉬워요.”

책을 읽고 나면 누군가와 이야기하고 싶은 순간이 있습니다.

하지만 기존 독서모임은 정기적으로 참여해야 하거나, 새로운 사람들과 관계를 만들어야 한다는 부담이 있습니다.

책장사이는 사람을 오래 알아가야 하는 모임보다,**한 권의 책에 집중해 짧고 깊게 이야기할 수 있는 공간**이 있으면 어떨까? 라는 질문에서 출발한 서비스입니다. 

책을 좋아하지만 독서모임이 부담스러웠던 사람들을 위해, **익명으로 가볍게 참여하고 책 이야기만 남길 수 있는 서비스**를 만들고자 합니다.

## 🏁 로컬에서 시작하기

#### 1. 환경 변수 설정

프로젝트 루트에 `.env` 파일을 생성하고 필요한 환경 변수를 입력합니다.

> [!CAUTION]
> `.env`와 Firebase 서비스 계정 JSON 등 민감한 파일은 Git에 커밋하지 마세요.

```env
# Database
DB_HOST=
DB_PORT=3306
DB_NAME=
DB_USERNAME=
DB_PASSWORD=

# Redis
REDIS_HOST=
REDIS_PORT=6379

# Social Login
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
APPLE_CLIENT_ID=
KAKAO_CLIENT_ID=
KAKAO_CLIENT_SECRET=

# External API
KAKAO_REST_API_KEY=
DATA4LIBRARY_AUTH_KEY=
GEMINI_API_KEY=

# JWT
JWT_SECRET=

# CORS
CORS_ALLOWED_ORIGINS=

# Firebase Cloud Messaging
FIREBASE_ENABLED=false
FIREBASE_PROJECT_ID=
GOOGLE_APPLICATION_CREDENTIALS=
```

<details>
<summary><b>환경 변수 설명 보기</b></summary>
<br>

| 변수 | 설명 |
| :--- | :--- |
| `DB_HOST` | MySQL 서버 호스트 |
| `DB_PORT` | MySQL 서버 포트 |
| `DB_NAME` | 사용할 데이터베이스 이름 |
| `DB_USERNAME` | MySQL 사용자 이름 |
| `DB_PASSWORD` | MySQL 비밀번호 |
| `REDIS_HOST` | Redis 서버 호스트 |
| `REDIS_PORT` | Redis 서버 포트 |
| `GOOGLE_CLIENT_ID` | Google 로그인 Client ID |
| `GOOGLE_CLIENT_SECRET` | Google 로그인 Client Secret |
| `APPLE_CLIENT_ID` | Apple ID Token의 Audience 검증값 |
| `KAKAO_CLIENT_ID` | Kakao 로그인 Client ID |
| `KAKAO_CLIENT_SECRET` | Kakao 로그인 Client Secret |
| `KAKAO_REST_API_KEY` | Kakao 도서 검색 API 키 |
| `DATA4LIBRARY_AUTH_KEY` | 도서관 정보나루 API 인증 키 |
| `GEMINI_API_KEY` | Google Gemini API 키 |
| `JWT_SECRET` | JWT 서명 키—32바이트 이상의 안전한 임의 문자열 |
| `CORS_ALLOWED_ORIGINS` | 허용할 Origin—여러 개일 경우 쉼표로 구분 |
| `FIREBASE_ENABLED` | Firebase Cloud Messaging 활성화 여부 |
| `FIREBASE_PROJECT_ID` | Firebase 프로젝트 ID |
| `GOOGLE_APPLICATION_CREDENTIALS` | Firebase 서비스 계정 JSON 파일 경로 |

</details>

#### 2. 애플리케이션 빌드

```bash
./gradlew build
```

#### 3. 애플리케이션 실행

```bash
./gradlew bootRun
```

애플리케이션은 기본적으로 다음 주소에서 실행됩니다.

```text
http://localhost:8080
```

> [!TIP]
> 첫 실행 시 Flyway가 데이터베이스 마이그레이션을 자동으로 수행합니다.

<br>

## 🧹 코드 포맷

Google Java Format을 기반으로 한 Spotless를 사용합니다.

```bash
# 코드 포맷 자동 적용
./gradlew spotlessApply

# 코드 포맷 검사
./gradlew spotlessCheck
```

Pull Request를 생성하기 전에 다음 명령어로 포맷과 테스트를 함께 확인하는 것을 권장합니다.

```bash
./gradlew spotlessCheck build
```

> [!NOTE]
> GitHub Actions에서도 `spotlessCheck`와 `build`가 자동으로 수행됩니다.
